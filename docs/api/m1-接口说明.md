# M1 接口说明 — 账号与空间(给前端)

> 本文档是前后端对接契约的**人话版**;机器版契约见 `docs/api/openapi.json`
> (可用 `openapi-typescript` 直接生成 TS 类型)。改路由后后端会重导,前端类型随之更新。

## 0. 通用约定

- Base URL:`http://localhost:8000`(开发),所有接口前缀 `/api/v1`
- 认证:`Authorization: Bearer <access_token>`
- **成功**:直接返回数据体(HTTP 200/201/204)
- **失败**:一律统一壳,前端按 `error.code`(稳定字符串码)做提示映射:

```json
{ "success": false, "error": { "code": "SPACE_NOT_FOUND", "message": "空间不存在", "details": null } }
```

- 422 参数校验:`code=VALIDATION_ERROR`,`details` 为字段级错误数组

## 1. 认证流程(前端需要实现的时序)

```
注册/登录 ──▶ 拿到 { access_token, refresh_token, user, spaces[] }
         ──▶ access_token 存内存/localStorage,axios 拦截器统一带 Authorization
         ──▶ 用户选空间(或点击切换空间)──▶ POST /auth/switch-space(带上 refresh_token)
              → 返回**新的** token 对(旧 refresh 立即作废,必须覆盖保存!)
访问中收到 401/TOKEN_EXPIRED ──▶ 用 refresh_token 调 /auth/refresh 换新对,重试原请求
refresh 也 401 ──▶ 清空本地凭据,跳登录页
登出 ──▶ POST /auth/logout(带 refresh_token)──▶ 清空本地凭据
```

**要点**:
- `refresh_token` 是一次性的:每次 /refresh 和 /switch-space 都会换新,响应里的新 token 必须**立刻覆盖存储**
- `spaces[]` 在登录/注册/刷新响应里都带,用于渲染空间切换器;`role` 是当前用户在该空间的数值角色(40=Owner 30=Admin 20=Editor 10=Viewer)
- 改密成功后**所有会话失效**,前端需跳登录页

## 2. 接口清单

### 认证 `/api/v1/auth`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/register` | 无 | 注册并直接登录,201 返回 token 对 |
| POST | `/login` | 无 | 登录 |
| POST | `/refresh` | 无 | 用 refresh_token 换新 token 对 |
| POST | `/logout` | Bearer | 登出,撤销提供的 refresh_token,204 |
| POST | `/switch-space` | Bearer | 切换活动空间,轮换 token 对 |

**POST /register** 请求:`{"username": "alice", "nickname": "爱丽丝", "password": "至少8位"}`
(username:3-32 位字母/数字/`_`/`-`;失败码:`USERNAME_TAKEN` 409)

**POST /login** 请求:`{"username": "alice", "password": "..."}`
失败码:`INVALID_CREDENTIALS` 401(不区分账号不存在/密码错误)

**成功响应**(register/login/refresh/switch-space 共用):

```json
{
  "user": { "id": "uuid", "username": "alice", "nickname": "爱丽丝", "created_at": "..." },
  "spaces": [ { "id": "uuid", "name": "研发空间", "description": "", "role": 40 } ],
  "access_token": "eyJ...",
  "refresh_token": "eyJ不透明随机串",
  "token_type": "bearer",
  "expires_in": 86400
}
```

**POST /switch-space** 请求:`{"space_id": "uuid", "refresh_token": "当前有效的refresh"}`
失败码:`SPACE_NOT_FOUND` 404(非成员与不存在同语义)、`REFRESH_TOKEN_INVALID` 401

### 用户 `/api/v1/users`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/me` | Bearer | 当前用户资料 |
| PATCH | `/me` | Bearer | 改昵称 `{"nickname": "..."} ` |
| POST | `/me/password` | Bearer | 改密 `{"old_password": "...", "new_password": "..."}`,204;成功后所有会话失效 |

失败码:`INVALID_CREDENTIALS` 401(原密码错)、`VALIDATION_ERROR` 400(新旧相同)

### 空间 `/api/v1/spaces`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/` | Bearer | 我的空间列表 `[{id,name,description,role,created_at}]` |
| POST | `/` | Bearer | 创建 `{"name": "...", "description": ""}`,201,创建者成为 Owner |
| GET | `/{space_id}` | Bearer | 空间详情(含我的 role) |
| PATCH | `/{space_id}` | Admin+ | 改名/描述 |
| DELETE | `/{space_id}` | Owner | 删除空间,204(级联删成员,不可恢复) |
| GET | `/{space_id}/members` | 成员 | 成员列表 `[{user_id,username,nickname,role,joined_at}]` |
| POST | `/{space_id}/members` | Admin+ | 添加成员 `{"username": "对方账号", "role": 20}`,201 |
| PATCH | `/{space_id}/members/{user_id}` | Admin+ | 改角色 `{"role": 20}`;`role=40` 表示**转让所有权**(自己降为 Admin) |
| DELETE | `/{space_id}/members/{user_id}` | Admin+ | 移除成员,204(不能移自己/不低于自己的成员) |
| POST | `/{space_id}/leave` | 成员 | 退出空间,204(Owner 不能退出) |
| GET | `/{space_id}/audit-logs?limit=50&offset=0` | Admin+ | 审计分页 `{items:[{id,actor_id,action,target,detail,ip,created_at}], total}` |

失败码:`SPACE_NOT_FOUND` 404(非成员/不存在)、`FORBIDDEN` 403(角色不足)、
`USER_NOT_FOUND` 404(添加时对方未注册)、`MEMBER_ALREADY` 409、`MEMBER_NOT_FOUND` 404

## 3. 角色权限矩阵(前端显隐依据)

| 操作 | Viewer(10) | Editor(20) | Admin(30) | Owner(40) |
|------|:---:|:---:|:---:|:---:|
| 查看空间/成员列表 | ✓ | ✓ | ✓ | ✓ |
| 修改空间信息 / 添加成员 / 改角色 / 移除成员 / 看审计 | ✗ | ✗ | ✓ | ✓ |
| 删除空间 / 转让所有权 | ✗ | ✗ | ✗ | ✓ |
| 添加成员的角色上限 | - | - | 只能授 Editor/Viewer | 可授 Admin 及以下 |
| 修改/移除的目标限制 | - | - | 只能操作低于自己的成员 | 同左(Owner 本身只能被转让) |

## 4. 错误码总表(M1 范围)

| 稳定码 | HTTP | 场景 |
|--------|------|------|
| VALIDATION_ERROR | 400/422 | 参数不合法(details 有字段明细) |
| NOT_FOUND | 404 | 资源不存在(通用) |
| AUTH_REQUIRED | 401 | 未携带/无效 access token → 直接去刷新或登录 |
| TOKEN_EXPIRED | 401 | access token 过期 → 用 refresh 换新后重试 |
| INVALID_CREDENTIALS | 401 | 登录失败/原密码错误 |
| REFRESH_TOKEN_INVALID | 401 | refresh 失效(已轮换/过期)→ 清凭据回登录页 |
| USERNAME_TAKEN | 409 | 注册账号重复 |
| USER_NOT_FOUND | 404 | 添加成员时对方账号不存在 |
| MEMBER_ALREADY | 409 | 对方已是成员 |
| FORBIDDEN | 403 | 已登录/已是成员但角色不足 |
| SPACE_NOT_FOUND | 404 | 空间不存在或你不是成员 |
| MEMBER_NOT_FOUND | 404 | 目标成员不存在 |
| INTERNAL_ERROR | 500 | 服务端错误(前端只提示"稍后重试") |
