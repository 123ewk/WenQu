## 1. 落地内容

- 新配置 **`APP_TRUSTED_PROXIES`**(deploy/.env.example 有注释):逗号分隔可信代理网段(CIDR),
  如 `"127.0.0.1,10.0.0.0/8"`;**留空 = 不信任任何代理**(默认,fail-closed,与从前行为逐字一致);
- 取值收口在 `server/src/app/core/client_ip.py:resolve_client_ip`,登录 `last_login_ip` 与
  全部审计 `ip`(含 403 被拒记录)共用:仅当**直连对端 ∈ 可信网段**才解析 `X-Forwarded-For`,
  自右向左剥掉可信跳,第一个不可信地址即客户端;链上出现非法值整条不采、回落直连地址。
  **不可信客户端伪造 XFF 无效**(有专项测试钉住);
- 验证:单测 11(含 IPv6/多跳/污染链)+ 端到端集成 1(真库登录 IP + 被拒审计 IP);
  ruff/mypy 0 错,全量 262 单测 + 37 集成绿,契约 drift 测试绿(openapi 未重导,34 路径/50 方法不变)。
