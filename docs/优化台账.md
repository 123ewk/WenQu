| 头像上限写进契约 | FastAPI 无法把运行时配置值写进静态契约(可配项) |

## 4. 维护规则(优化侧)

- **新增优化项** → 按 §0 的格式加进 §1 或 §2,写清来源、延后理由、触发条件、归属里程碑;
- **完成优化项** → 从本表移除,提交信息写明 `OPT-xx`,并在 `docs/V1交付台账.md` §2 补模块台账;
- **基准裁剪变化** → 同时更新 `docs/架构设计.md` §11(完整登记)与本表 §2(触发条件的通俗表述);
- **前端不受影响是硬约束** → 会改契约的项先确认前端 L0 已达标,否则推迟(见 §1.1)。
