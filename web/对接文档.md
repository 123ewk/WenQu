## 1. 事实来源与裁决规则(冲突时怎么判)

优先级:

1. **`docs/api/openapi.json`**(机器契约)——字段名、端点、枚举、必填性以此为准;

### 2.5 流式链路的既知约束(OPT-1 / OPT-2 / OPT-3 已交付;OPT-12 已交付)

- **心跳帧**:生成等待期发 `: ping` 注释行;解析时**跳过所有不以 `data: ` 开头的行**即可;
- **失败必发 `error` 且不发 `done`**(`f4a1478`):检索失败带 `code`,检索兜底与模型调用失败只有人话 `message`
  (源码 `server/src/app/application/service/qa.py`)→ **按 code 分支前先判空**,且**不要拿 `done` 当唯一结束信号**;
- **断线续流已交付**:断开连接后后端**宽限 5 秒**继续生成(`APP_STREAM_GRACE_SECONDS` 可配),期间重连取消宽限;
  耗尽无人回来才中止:close 上游 + 部分答案落库 + 流内 `done(partial=true)` 收尾;
  **所有事件载荷带单调 `seq`**(从 1 起,按生成流独立计数)——前端续流的游标;
- **OPT-4/OPT-5 落地后的口径**:检索命中的是父块内部的**子块**,返回并引用的是**父块**——

  同一父块的多个子块命中**去重成一条引用**;`chunk_count` 与分块列表 `total` **只统计父块**;
  流水线已拆成插件链,阶段边界与事件形态不变;

## 3. 对接流程(固定 5 步,不跳步)

1. **同步契约** —— 以 `docs/api/openapi.json` 为准(当前基线 **39 路径 / 59 方法**,OPT-25 新增 5 个 `/admin/*` superuser 端点不接入);后端重导后随其提交同步;确认目标端点/字段已在契约中(L0 判据);
2. **类型与 API 层** —— 先在 `src/api/types.ts` 与 `src/api/*.ts` 落地类型与函数;**只有 `src/api/` 允许 import axios**;401 刷新链等横切逻辑只能有一处实现;
3. **页面接入** —— 组件只调 API 函数,不直接拼 URL;三态(loading/空/错误)与角色显隐一并做,不留"稍后补";
4. **冒烟** —— 按 §7 的环境基线跑真实链路,不满足"只看端口/只看构建通过";
5. **登记** —— 新发现的缺口写进 §11 缺口台账(含证据:实测响应或源码位置);契约与文档的矛盾也记在这里。

**提交粒度**:一个可验证的小功能一个提交,判断标准是该提交**能否独立说清做了什么、怎么验证**;
文档改动与代码改动宜分开;每次提交前跑 §4 第 6 条的构建检查。合并到 `main` 由前端侧直接快进推送
(`git push origin <branch>:main`),不必为前端单独开长期分支或 PR。

## 8. 认证链路与 Token 键名

### 8.1 localStorage 键名

| 键 | 内容 |
|---|---|
| `wenqu_access_token` | 访问令牌(请求拦截器自动附带 `Authorization: Bearer`) |
| `wenqu_refresh_token` | 刷新令牌(**一次性**,每次 refresh/switch-space 后立即用新值覆盖) |
| `wenqu_user` | UserOut JSON(F5 恢复登录态;**`current_space_id` 随此键持久化**,活动空间以契约为准) |
| `wenqu_spaces` | SpaceBriefOut[] JSON(含各空间 role) |
| `wenqu_sidebar_collapsed` | 侧边栏折叠状态 |

> 原独立自管键 `wenqu_current_space_id` 已废弃删除,模块加载时对老用户残留做一次性清理。

### 8.2 认证链路(实现于 `src/api/http.ts` + `src/stores/auth.ts`)

1. 请求拦截器统一附带 Bearer access_token;
2. 收到 401 且 `error.code ∈ {AUTH_REQUIRED, TOKEN_EXPIRED}`(或裸 401)→ 用 refresh_token 调 `/auth/refresh` → 成功后**重放原请求(仅一次)**;
3. **并发 401 防抖**:共享 `refreshAccessToken()` 的 refreshing Promise,多个请求同时过期只刷新一次;
4. refresh_token 一次性:刷新/切空间成功后新值**立刻覆盖**旧存储值;
5. 刷新失败(`REFRESH_TOKEN_INVALID`)→ 清空凭据 → 跳登录页(带 `redirect`);网络错误不清凭据;
6. 切换空间:响应是完整 AuthResponse,前端**整体替换** user/spaces/双令牌;令牌轮换类操作在 Store 内**串行执行**(内部函数不叠加串行,防嵌套死锁);
7. 改密成功(204)→ 后端吊销全部会话 → 清凭据并强制回登录页;
8. `/auth/login|register|refresh|switch-space|logout` 自身的 401(如密码错误)不触发刷新链;

### 9.1 流式问答(SSE,02 页,`src/api/chat.ts`)

- 用 `fetch` + `ReadableStream` 读取(**不能用 EventSource**:发不了 POST body 与 Authorization 头);
- 五种事件按 `type` 分派:`meta`(新会话 id,同步路由/侧栏)、`citations`、`delta`(**累加**正文)、`done`(`cited_indexes` 决定抽屉展示哪几条)、`error`(展示错误、停 loading,**HTTP 仍 200**);
- `error` 的 `code` **可选**(§2.5):按 code 分支前判空;**失败路径不发 `done`**,收尾按 `done`/`error`/都没有三种情况处理;
- 错误文案:503 `MODEL_NOT_CONFIGURED` → "联系管理员检查服务端模型密钥";502 `MODEL_CALL_FAILED` → "稍后重试",勿混;
- **断线续流已接入**(OPT-3):事件携带单调 `seq`,组件记录最后收到的 `seq`;流中断且已有 `seq` 时自动调
  `GET .../conversations/{cid}/stream?after=<seq>` 精确补播(服务端按 seq 续,前端无需去重),
  不可续(404 `STREAM_NOT_RESUMABLE`)或续流再失败 → 回退既有收尾(重拉 messages / 提示);
- `done` 可能带 `partial=true`(宽限耗尽中止):正文是已生成的部分答案,消息尾部显示"连接中断,以上为已生成的部分回答"提示;
- 首次提问由后端新建会话:`router.replace` 会触发历史重拉,而失败/中断路径后端**不一定**存助手消息
  (中断且宽限耗尽时会存部分答案)→ 用 `skipReloadId` 对刚流式结束的会话跳过一次重拉;
- 流无声结束(网关掐断/断网):自动续流;失败且有部分正文 → 保留正文 + partial 提示;无正文 → 重拉历史,取不到给可读提示,不得留白;
- 引用角标 `[n]` 打开 380px 抽屉;"查看完整原文"按 `chunk_id` 调单块全文接口(限高滚动,缓存;404 → "原文档已删除");

- 停止生成:`AbortController`;断线恢复逻辑不变(回退重新拉取,不做 resume UI);
- 会话重命名:`title` 1–128 字,成功后就地更新列表项(不整表重拉);重命名后按 `updated_at` 排最前属预期;

  显式选择即生效(后端已修 model_id 语义冲突:检索向量化改取目标 KB 的 `embedding_model`,
  `SearchRequest.model_id` 废弃不再使用);**选择器是组件本地状态,F5 后回到"默认模型"**(不持久化,见 §11.7);
- **Agent 工具循环已接入**(OPT-10):输入行 `el-switch` 开关提交请求级 `agent` 参数(默认关;F5 后复位为关,组件本地状态)。

  实时卡按 id 配对渲染"正在检索 → 已检索(Nms)/检索失败",`output`(≤2000 字)是**截断展示文本**,当预览渲染不当全文;
  **工具失败只 `tool_result.ok:false` 且循环继续**(不是 `error` 事件),整卡标题按"有无失败调用"点色;
  **agent 模式 `citations` 为空数组是正常路径**(模型如实回答未找到),不得按错误处理;
- **`agent_steps` 回放**:`MessageOut.agent_steps`(JSONB,迁移 0011 起落库)非空时渲染历史 Agent 工具卡(轮次/思考/每次调用 query+预览,
  字段与实时事件等价);**null/缺失(直检消息、0011 之前的存量消息)回退既有 `citations` 合成卡**,两卡互斥,实时流结束后把本轮
