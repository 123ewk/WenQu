## 二、M2 已对接页面中发现的接口缺口

1. **知识库缺少聚合统计**:原型卡片与详情页头展示"文档数 / 分块数 / 存储量 / 索引状态 / 更新时间";`KnowledgeBaseOut` 只有 `name/description/embedding_model/embedding_dim/created_at`。
   - 卡片:不渲染统计,底部只显示嵌入模型与创建时间;
   - 详情页头:文档数改用 `GET .../documents` 的 `total`,分块数与存储量无法获得,未渲染。

2. **文档"重新解析"无接口**:原型每行与分块抽屉头部都有「重新解析」;契约只有上传/列表/详情/删除。
   - 处理:列表行不渲染该按钮;分块抽屉保留按钮但提示"请删除后重新上传"。

3. **文档失败原因只到 error_code**:`error_code=INGEST_FAILED` 不携带人话原因与失败阶段(DocumentOut 无 parsed_at 等耗时字段)。
   - 处理:失败行展开按接口文档约定文案提示;原型里的"耗时 12.4s"等进度时长无数据来源,未渲染。

4. **检索调参无接口**:原型 Tab B 的向量权重滑块、关键词权重、相似度阈值、Rerank 开关、以及空间设置的"默认检索参数"在 `SearchRequest` 中都不存在(仅 `query/top_k/kb_ids/model_id`)。
   - 处理:仅保留 topK 与检索按钮;权重/阈值/Rerank 未渲染。空间设置 Tab 以说明文案占位。

5. **嵌入模型不可选择、无重建索引**:`CreateKBRequest/UpdateKBRequest` 只有 `name/description`,没有模型字段,也没有模型列表接口(实际由服务端 `dashscope/text-embedding-v3` 等配置决定)。
   - 处理:新建弹窗去掉模型选择器与黄色重建警示;详情设置页只展示当前模型并说明不可更换。

6. **会话不能重命名**:原型会话项 hover 有重命名图标;契约只有列表/新建/删除/消息。
   - 处理:仅保留删除;标题由后端取首个问题生成(实测返回问题文本),前端不可改。

7. **会话标题与排序依赖后端**:`ConversationOut.title` 由后端生成(首问文本),`created_at/updated_at` 用于分组;契约未定义排序,前端按返回顺序渲染。

8. **`AskRequest` 无重试/编辑重发**:流内 `error` 事件后无法请求重试;错误消息需用户再次提问。
   - 处理:错误以红色提示条展示,不提供"重试"按钮。

9. **分块类型只有 text/table**:原型分块列表的"标题/段落/表格"三分类中,标题块后端不区分(`meta.kind` 仅 `text|table`)。
   - 处理:按两分类展示,"标题"归入段落。

10. **分块 token 数缺失**:`ChunkOut` 无 `tokens` 字段(仅预览接口 `ChunkPreviewItem.tokens` 有)。
    - 处理:列表右侧改显示字符数。

11. **引用抽屉不能看完整原文块**:接口文档明确 M2 不提供"查看完整原文块"接口,`excerpt` 为前 300 字截断。
    - 处理:抽屉只展示 excerpt,保留「查看文档」跳转知识库详情。

12. **`POST /chunks/preview` 未接入页面**:这是独立调参接口(不落库),原型没有对应页面(05 是文档分块列表而非试切)。
    - 处理:API 层已封装(`src/api/retrieval.ts`),暂无 UI 入口;若需要"分块试切"页可后续接入。

## 三、M1 遗留缺口(仍存在)

1. **审计日志筛选/导出/结果列**:`docs/api/openapi.json` 已新增 `action/actor_id/since/until` 四个筛选参数(m1 接口说明「审计日志(已增强)」一节),
   但**当前后端实现尚未生效**(实测带 `action=space.created` 仍返回全部记录、非法 action 返回 200 而非 422),
   因此前端仍未渲染筛选条;待后端上线后可直接接入。导出与成功/拒绝结果字段仍无契约。
2. **审计操作人**:`actor_id` 仅 UUID,前端用成员列表建映射;非本空间成员退化为短 UUID。
3. **当前活动空间 ID**:AuthResponse 未返回,前端自维护 `localStorage.wenqu_current_space_id`。
4. **头像上传**:`UserOut` 无头像字段,无上传接口,未渲染入口。
5. **个人中心元信息**:无"上次登录时间/IP"接口。
6. **顶栏全局上传进度**:仅能反映浏览器上传阶段(axios onUploadProgress);入队后的解析/分块/向量化进度需在文档列表看,无跨页面聚合接口。
7. **无邮箱体系**:M1 用户只有 `username`,邀请成员按注册账号添加。

> 审计动作码:前端标签已覆盖后端 `AuditAction` 全部 16 项(含 M2 的 `kb.created/kb.updated/kb.deleted/document.uploaded/document.deleted`);未知码原样展示,便于后端新增动作时不致显示空白。
